# 3D Spire

React + Vite site for 3D Spire. Below-the-fold sections and the 3D viewer (`@google/model-viewer`) are lazy-loaded.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Edit the WhatsApp number in `src/config.js` (replace `[YOUR-NUMBER]`).
Pushes to `main` deploy to GitHub Pages via `.github/workflows/deploy.yml`.
